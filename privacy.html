Privacy Policy

This policy applies to the personal developer tools described on the home page.

Who uses these tools

The tools are used solely by their developer. They are not offered to the public, and no other person is asked to sign in or grant access.

Data accessed

The tools access only data in the developer's own Google account, and only within the permissions the developer grants when authorizing each tool.

How data is used

Data is used only to perform the task each tool was built for, such as reading and writing the developer's own files. Data is not sold, is not shared with third parties, and is not used for advertising.

Storage and security

Data stays in the developer's Google account and on systems the developer controls. Access credentials are stored as encrypted secrets.

Revoking access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions.
